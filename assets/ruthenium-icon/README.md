# Ruthenium icon

Minimal adaptive icon built around the open-globe mark only. The graphite
background is full bleed; the silver globe is centered on a 52 dp circular
keyline. Separate foreground, background, monochrome, Google Play, mask, and
small-size assets are generated by the command below. It also creates the
density-specific resources under `android-res/` that replace Chromium's
launcher assets without adding new Android resource names.

The `ruthenium-round-*` assets apply a `+0.1 dp, 0 dp` optical correction
for the open lower-right segment. The default adaptive and Google Play artwork
remain geometrically centered.

```sh
python3 scripts/make_ruthenium_icon.py assets/ruthenium-icon
```
